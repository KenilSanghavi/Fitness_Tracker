# Description
Fitness tracker System is a Python application which is made using certain libraries like pandas,numpy,seaborn and matplotlib
It helps the users to record daily activity,store it in the csv file 
It allows users to:
Log activity
Store activity
calculate fitness metrics
filter activity by type or date range
generate report
